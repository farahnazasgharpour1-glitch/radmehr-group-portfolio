# رادمهر گروپ — نسخه نهایی پورتفولیو

این پروژه یک وب‌سایت چندصفحه‌ای استاتیک با HTML، CSS و JavaScript بومی است.

## اجرا و انتشار
- فایل `index.html` در ریشه، صفحه اصلی است.
- مخزن برای انتشار با GitHub Pages آماده شده است.
- پس از عمومی‌شدن مخزن و موفقیت اولین اجرای GitHub Actions، نشانی سایت در این مسیر خواهد بود: `https://farahnazasgharpour1-glitch.github.io/radmehr-group-portfolio/`.
- در تنظیمات مخزن، بخش Settings → Pages، گزینهٔ Source باید روی GitHub Actions قرار بگیرد.

## ساختار
- `index.html` — صفحه اصلی
- `html/` — درباره، خدمات، پروژه‌ها، تماس، حریم خصوصی و تشکر
- `css/` — استایل‌های مشترک و اختصاصی
- `js/` — تعاملات بومی مرورگر
- `images/` — تصاویر WebP و لوگوهای SVG
- `font/Estedad.woff2` — فونت Estedad با مجوز OFL همراه
- `robots.txt`, `sitemap.xml`, `404.html` — فایل‌های crawl و خطا

## یادداشت‌ها
- حرکت‌ها و تعاملات با JavaScript بومی و فایل GSAP محلی اجرا می‌شوند.
- فرم تماس از Web3Forms استفاده می‌کند؛ ارسال واقعی باید بعد از انتشار آزمایش شود.
- صفحه حریم خصوصی هنوز نیازمند اطلاعات مسئول واقعی سایت و تعیین retention است.
- آزمون Lighthouse/مرورگر واقعی پس از Deploy الزامی است؛ این بسته به‌تنهایی تضمین‌کننده نمره سرعت مشخص نیست.
- این وب‌سایت یک پروژهٔ مفهومی برای نمونه‌کار است و نباید به‌عنوان وب‌سایت رسمی یا پروژه‌های اجراشده معرفی شود.
