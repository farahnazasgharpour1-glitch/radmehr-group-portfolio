بسته لوگوی Radmehr Group — نسخه مفهومی قابل‌ویرایش

فایل‌ها:
- radmehr-logo-horizontal-gold.svg : لوگوی افقی با نشان طلایی و نوشته روشن؛ مناسب هدر تیره.
- radmehr-logo-horizontal-light.svg : نسخه تک‌رنگ روشن؛ مناسب پس‌زمینه تیره.
- radmehr-mark-gold.svg : نشان مستقل برای استفاده‌های کوچک‌تر.
- favicon.svg : فاوآیکون با پس‌زمینه زغالی و نشان طلایی.

نصب پیشنهادی:
1) این فایل‌ها را در پوشه images پروژه کپی کنید.
2) در HTML هدر، به‌جای متن لوگوی فعلی (اگر وجود دارد) از این ساختار استفاده کنید:

<a class="brand" href="./index.html" aria-label="رادمهر گروپ، صفحه اصلی">
  <img src="../images/radmehr-logo-horizontal-gold.svg" alt="Radmehr Group" width="260" height="67">
</a>

3) چون فایل‌های index.html و contact.html شما هر دو داخل پوشه html هستند، مسیر ./index.html از هر دو صفحه به صفحه اصلی می‌رسد.
4) CSS پایه:

.brand { display: inline-flex; align-items: center; flex: 0 0 auto; }
.brand img { display: block; width: clamp(175px, 22vw, 260px); height: auto; }

در گام بعدی، برای ادغام دقیق و ساخت منوی همبرگری باید CSS و HTML فعلی هدر سایت بررسی شوند.

یادداشت: این لوگو یک طرح برداری مفهومی است؛ پیش از استفاده تجاری نهایی، بهتر است تناسبات و جزئیات آن یک بار در اندازه‌های واقعی مرور و تثبیت شود.


تصاویر بخش پروژه‌ها:
- radmehr-project-villa.webp : نسخهٔ بهینه‌شدهٔ تصویر ویلای مفهومی برای کارت پروژه.
- radmehr-project-residential.webp : نسخهٔ بهینه‌شدهٔ تصویر مجتمع مسکونی مفهومی برای کارت پروژه.
- radmehr-project-office.webp : نسخهٔ بهینه‌شدهٔ تصویر ساختمان اداری مفهومی برای کارت پروژه.
- فایل‌های PNG اصلی برای نگهداری و امکان ویرایش بعدی حفظ شده‌اند؛ صفحهٔ اصلی از نسخه‌های WebP کم‌حجم استفاده می‌کند.

رفتار کارت‌ها: با انتخاب «جزئیات بیشتر»، کارت باز می‌شود و توضیحات کنار تصویر قرار می‌گیرد. برای جلوگیری از شلوغی صفحه، در هر لحظه فقط یک کارت باز می‌ماند؛ کلید Escape نیز جزئیات باز را می‌بندد.


تصاویر مفهومی گالری معماری (نسخهٔ بهینه‌شده برای وب):
- radmehr-concept-villa.webp : طرح مفهومی ویلای مدرن؛ نسبت‌دادن آن به پروژهٔ اجراشده مجاز نیست.
- radmehr-concept-interior.webp : طرح مفهومی فضای داخلی معاصر.
- radmehr-concept-office.webp : طرح مفهومی ساختمان اداری؛ از برش تصویر معماری تولیدشده و تبدیل‌شده به WebP تهیه شده است.

این سه فایل برای سبک نگه‌داشتن صفحه با ابعاد مناسب و فشرده‌سازی WebP ذخیره شده‌اند. متن‌های جایگزین در HTML توصیفی هستند و سکشن به‌صورت جدا از سه کارت پروژهٔ مفهومی نگه داشته شده است.
